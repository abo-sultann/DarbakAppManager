# DarbakAppManager

**دربك للتطبيقات** — مدير تطبيقات آمن وخفيف مخصص لشاشة السيارة Android 7.1 / API 25 بدقة 1024×600.

## قواعد المشروع
- التعامل افتراضيًا مع تطبيقات المستخدم فقط.
- تطبيقات النظام والمصنع محمية ولا تدخل في الحذف أو التنظيف.
- تنظيف البقايا يقتصر على مسارات خارجية معروفة وحزم غير مثبتة.
- البقايا المؤكدة تُحدد تلقائيًا فقط عندما يكون حذف التطبيق مسجلًا بواسطة DarbakAppManager؛ بقية المرشحات تحتاج اختيارًا يدويًا.
- التنظيف الأول ينقل الملفات إلى العزل؛ الحذف النهائي من العزل عملية منفصلة ومؤكدة.
- لا Root، لا Firebase، ولا خدمات إنترنت مطلوبة.
- Native Android خفيف، RTL، Landscape، 1024×600، بدون حركات ثقيلة.
